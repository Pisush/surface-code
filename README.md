# surface-code

A distance-*d* surface code error-correction playground in Go: bit-flip noise,
Z-stabilizer syndrome extraction, a union-find decoder, and a Monte Carlo
threshold estimator.

Work in progress — see the milestone pull requests:

- **M1** — lattice, coordinates, noise model, syndrome extraction
- **M2** — union-find decoder (Delfosse–Nickerson style)
- **M3** — `cmd/threshold` Monte Carlo driver + threshold plot
